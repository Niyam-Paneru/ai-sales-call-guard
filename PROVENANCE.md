# Provenance

This is a sanitized policy slice from guarded outbound-call experiments inside private DentSignal work.

## Preserved

- separate self-test and external-call capabilities;
- suppression and privacy hard gates;
- explicit enablement switches;
- disclosure gate;
- daily limit behavior;
- default deny for unknown modes.

## Rewritten for public review

Provider transport, credentials, real contact data, campaign data, and operational call flows are excluded.

## Claim boundary

This repository does not place calls and does not claim legal approval for any jurisdiction. It demonstrates how a call request can be denied before transport.
